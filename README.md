## 🚀 Getting Started

### Prerequisites

Make sure you have Python and Jupyter installed. You can install the required libraries with:

```bash
pip install numpy pandas matplotlib jupyter
```

### Running the Notebooks

1. Clone this repository:
```bash
   git clone https://github.com/Shivkoirala1/Smart-data-dictionary-Python.git
```

2. Navigate into the folder:
```bash
   cd Smart-data-dictionary-Python
```

3. Launch Jupyter Notebook:
```bash
   jupyter notebook
```

4. Open any `.ipynb` file and start exploring!
